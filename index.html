A transit-style line map for DNA mutational analysis.

MutaMetro visualizes bioinformatics workflows the way transit maps trace cities. Each line represents an analysis strategy, each stop represents an analytical tool, and where paths cross represents consensus points.

Map Concepts

How to navigate the workflow map

Three core design concepts carry the whole system. Once these click, navigating complex pipelines becomes intuitive.

01 / Pipeline Lines

Continuous analytical paths

One colored path through the stops. Lines represent established setups like the Sarek (nf-core) workflow or standard GATK Best Practices, keeping choices consistent.

02 / Station Stops

Individual workflow tools

A node on the map represents a specific tool (e.g., BWA-MEM2, Mutect2). Alternative choices for the same macro-step sit stacked vertically for easy comparison.

03 / Interchanges

Where pipelines agree

Thick rings mark stations where multiple lines intersect. This visual consensus quickly highlights tools that are widely trusted across different standards.

Why MutaMetro?

Flexible recommendation guidelines

Instead of mandating a single rigid workflow, the task force agreed to publish recommended paths, detailed trade-offs, and tool options.

Assay Tuning

Flexible, not rigid

Recommendations adapt to lab requirements. Labs can swap tools provided sensitivity, specificity, and quality targets are fully validated.

Community Anchors

Standardized references

Public pipelines (e.g., Sarek, GATK Best Practices) anchor the map structure. In-house modifications can be overlayed and tested.

Multi-Depth detail

Dual Simple/Technical toggles

Switch view modes dynamically depending on your needs—revealing simplified explanations for clinical audits or exact terminal commands for developers.
